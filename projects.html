Library Management System

Java Application

An object-oriented library management application developed in Java. The system allows users to search for available media, borrow and return content, manage a wishlist, and rate items. Administrative features provide additional tools for managing library content and overdue records.

Key Features

  • User registration and login system
  • Search for books and audiobooks
  • Borrow and return library content
  • Rate previously borrowed content
  • Wishlist management
  • Administrative tools for managing content and overdue records

Technologies & Skills

Java Object-Oriented Programming HashMap Interfaces Inheritance
